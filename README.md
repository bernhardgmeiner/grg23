# grg23

Seite zum Workshop „Tools zeigen, Fragen klären“ (GRG 23 Alterlaa, 16.11.2026). Sie dient im Workshop als Präsentation und danach als Unterlage zum Nachmachen.

Online: https://bernhardgmeiner.github.io/grg23

- `index.html`: die ganze Seite in einer Datei (Schrift, Spiel und Prompt-Baukasten eingebettet, keine externen Abhängigkeiten)
- `img/`: Bilder zum Notebook-Beispiel und zu Canva

Bedienung: Leiste oben oder Pfeiltasten bzw. Bild-auf/Bild-ab (Klicker). „Vollbild“ vergrößert die Schrift für den Beamer.

Die Seite ist mit Unterstützung von KI (Claude) entstanden.
